How to verify manually in DevTools
  1. Open Network, clear the log, then answer several questions. Answer clicks should create no requests.
  2. Select the document request and inspect Response Headers. Confirm Content-Security-Policy contains connect-src 'none'.
  3. Open Application → Local Storage → www.histi.org. The assessment state is stored under the two HISTI keys shown above.
  4. Inspect the public source on GitHub. The assessment runtime does not transmit answer state.
