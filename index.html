How to verify manually in DevTools
  1. Open Network, clear the log, then answer several questions. Answer clicks should create no requests.
  2. Select the document request and inspect Response Headers. Confirm Content-Security-Policy contains connect-src 'none'.
  3. Open Application → Local Storage → histi.ocharlotted.com. The assessment state is stored under the two HISTI keys shown above.
  4. Inspect the public source on GitHub. The assessment runtime does not transmit answer state.

What Vercel still sees: ordinary requests needed to load the static site itself (for example HTML, JavaScript, CSS, the logo, and the static question module). Those requests happen independently of your answers and contain no assessment state. If you explicitly use Share, your browser/OS hands the generated result to the destination you choose.
