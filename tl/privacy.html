Patakaran sa pagkapribado

Dinisenyo ang HISTI upang manatili sa iyong browser ang mga sagot, progreso, at marka mo. Hindi ina-upload ng kasalukuyang mga pagninilay ang kalagayang iyon sa server ng aplikasyon ng HISTI.

Magnilay tungkol sa pagbabahagi nang hindi ibinibigay ang mismong impormasyon. Sa browser na ito ang mga pagpili at progreso mo. Maaari kang lumaktaw, huminto, o mag-reset.

Tingnan ang mga pagninilay →

1. Saklaw

Ipinapaliwanag ng patakarang ito ang mga gawain sa pagkapribado ng website at pagninilay ng HISTI sa www.histi.org. Ibinubukod nito ang impormasyong nakatago sa browser mo sa karaniwang teknikal na impormasyong pinoproseso kapag inihahatid ang isang website sa internet.

2. Nananatili sa device mo ang data ng pagninilay

Pinoproseso ng HISTI ang pagninilay sa browser mo. Maaaring itago ng kasalukuyang app ang mga sumusunod sa localStorage upang makapagpatuloy ka o makapagbalik-aral:

  • bersiyon ng pagsusulit, wika, at uri ng taong iniisip;
  • mga napiling antas, kalagayan ng mga sagot, at kasalukuyang pahina ng tanong;
  • mga kagustuhan sa accessibility at paggamit ng pagninilay; at
  • kung natapos na at kung may mga sagot na awtomatikong ginawa para sa pag-debug.

Hindi ipinapadala sa server ng aplikasyon ng HISTI ang kalagayang ito ng pagninilay. Mananatili ito sa profile ng browser at device kung saan mo ginagamit ang HISTI, maliban kung kusa mong kokopyahin o ibabahagi. Lokal na kinakalkula ang resulta mula sa mga sagot na iyon.

3. Walang cookies

Hindi nagtatakda o gumagamit ang HISTI ng cookies para sa kasalukuyang website o pagninilay. Hindi gumagamit ang HISTI ng cookies para sa advertising, analytics, o pagsubaybay.

Gumagamit ang HISTI ng localStorage para sa lokal na progreso ng pagninilay. Imbakan sa browser ang localStorage, ngunit hindi ito cookie. Maaari mo itong suriin o burahin gamit ang mga kontrol ng HISTI o mga kasangkapan ng browser para sa data ng site.

Itinatago ng panel ng Mga Setting sa buong site ang antas ng pagbasa, contrast, laki ng teksto, at performance mode sa hiwalay na rekord na nasa browser lamang, histi.preferences.v1. Walang sagot sa pagninilay ang mga kagustuhang ito at hindi sila ipinapadala sa server. Ang “I-reset ang mga setting” ay nagbubura lang ng rekord ng mga kagustuhan; hindi nito binubura ang progreso o resulta. Maaaring ilapat ng iba pang bukas na tab sa parehong site ang mga bagong kagustuhan sa pamamagitan ng lokal na storage event ng browser.

Isang minsanang tanda ng paglipat ng pahina sa sessionStorage ng tab na ito ang pumipigil sa muling pag-play ng panimula kapag bumalik sa home. Wala itong sagot o personal na detalye at binubura ito kapag binuksan ang home.

Tumutulong ang numerong posisyon ng pag-navigate sa session storage at history ng tab upang maiba ang Back sa Forward sa mga animasyon. Hindi nito itinatago ang mga binisitang URL, sagot, o personal na detalye, at hindi ito nagdaragdag sa history.

4. Mga pagpipilian, hindi totoong pribadong detalye

Walang malayang tekstong sagot o patlang para sa pangalan ng taong iniisip sa kasalukuyang Full, 120, 60, at School na pagninilay. Pumili lang ng antas o sagot. Huwag ilagay ang totoong pangalan, password, code, ID, o ibang sensitibong detalye.

Magkahiwalay ang lokal na progreso ng bawat wika, pagsusulit, at taong iniisip. Hindi kinokopya, isinasalin, pinapalitan, o binubura ng pagpapalit ng wika ang mga naka-save mong sagot. Bumalik sa parehong wika, pagsusulit, tao, at browser upang magpatuloy.

Binabago ng pop-up ng wika ang URL ng pahina. Hindi nito ipinapadala ang mga sagot sa serbisyong pagsasalin o nagtatago ng dagdag na rekord ng kagustuhan sa wika.

5. Ano ang nakikita ng karaniwang website hosting

Kailangan ng karaniwang network request para ma-load ang mga file ng website gaya ng HTML, JavaScript, CSS, logo, at nakapirming katalogo ng tanong. Naka-host sa Vercel ang HISTI, kaya maaaring magproseso ang imprastraktura ng hosting ng teknikal na impormasyon gaya ng:

  • IP address at tinatayang impormasyon ng network;
  • impormasyon ng browser, device, at protocol;
  • hinihinging URL o static na file;
  • oras ng request, katayuan ng tugon, at impormasyon para sa seguridad o pag-diagnose.

Hiwalay sa kalagayan ng pagninilay ang mga karaniwang request na ito. Hindi inilalagay ng HISTI ang mga sagot, progreso, o marka mo sa mga request na iyon.

Ipinaliliwanag ang sariling pangangasiwa ng Vercel sa impormasyong pang-imprastraktura sa Paunawa sa Pagkapribado ng Vercel.

6. Walang analytics, ad, o third-party na tagasubaybay habang ginagamit

Hindi naglo-load ang kasalukuyang pagninilay ng analytics SDK, advertising tracker, third-party na serbisyo ng font, o script ng pagsubaybay. Naka-host dito mismo ang Idiqlat, Tiro Gurmukhi, Instrument Sans, at subset ng Chinese font at nilo-load bilang mga static na file mula sa parehong origin.

Itinatakda ng patakaran ng browser sa production ang connect-src 'none' at form-action 'none', na humaharang sa mga karaniwang API ng pahina para sa fetch, XHR, WebSocket, EventSource, sendBeacon, at pagpapadala ng form.

7. Pagsuri sa lokal na data

Walang JSON export o talaan ng mga naka-save na resulta sa kasalukuyang pagninilay. Masusuri ang lokal na rekord sa mga developer tool ng browser: Application → Local Storage. Maaaring makita roon ang mga sagot ng sinumang gumagamit ng naka-unlock mong browser.

Maaaring may naiwang lokal na rekord ang mga lumang bersiyon ng HISTI, kasama ang opsyonal na mga label o kasaysayan ng resulta. Hindi binubura ng kasalukuyang pag-reset ang hindi kaugnay o mas lumang rekord. Burahin ang data ng site sa browser upang alisin ang lahat ng lokal na rekord nito.

8. Pagbura sa iyong lokal na data ng HISTI

Gamitin ang I-reset sa loob ng pagninilay upang alisin ang progreso at resulta ng pagsusulit, wika, at taong iyon mula sa kasalukuyang profile ng browser. Hindi naaapektuhan ang ibang pagninilay at Mga Setting. Bilang alternatibo, burahin ang data ng site para sa www.histi.org gamit ang mga setting ng browser.

Dahil hindi natatanggap ng HISTI ang kalagayan ng pagninilay, hindi nito kayang kunin o burahin mula sa malayo ang data na nasa browser mo lamang.

9. Lokal na pag-iimbak

Mananatili sa browser ang lokal na progreso ng HISTI hanggang i-reset mo ito, burahin ang data ng site, o alisin ito ng browser o device. Hindi sini-sync ang progreso sa ibang device, browser, o domain ng website.

Hindi ligtas na vault ang lokal na imbakan ng browser. Maaaring masuri ito ng sinumang may access sa naka-unlock mong profile o device. Sa device na may ibang gumagamit, i-reset ang pagninilay matapos gamitin. Burahin ang data ng site upang alisin ang lahat ng bersiyon at wika.

10. Pagbabahagi ng resulta

Hindi mo kailangang ipakita kaninuman ang iyong resulta. Hindi ito awtomatikong ibinabahagi, ina-upload, o inilalathala ng kasalukuyang pahina ng resulta. Kung magse-save ka ng screenshot, kokopya ng impormasyon, o magpapadala sa iba, suriin muna kung ano ang maihahayag nito.

Kapag pumili ka ng ibang app, serbisyo, o tao bilang pagpapadalhan, ang mga gawain sa pagkapribado ng pagpapadalhan ang masusunod.

11. Patakaran sa edad

Hindi para sa wala pang edad 13 ang HISTI Full, HISTI-120, at HISTI-60. May hiwalay at opsyonal na pagninilay sa klase ang HISTI para sa mga Paaralan: Middle School (edad 10–13) at High School (edad 14–18). Hindi humihingi ang HISTI ng petsa ng kapanganakan, totoong pangalan, school identifier, o pribadong katotohanan, at hindi gumagawa ng age profile. Bersiyon ang pipiliin mo, hindi eksaktong edad. May hiwalay na lokal na progreso bawat bersiyong pampaaralan at tao; hindi ginagalaw o muling ginagamit ang lumang rekord para sa binagong mga tanong. Parating pa ang ibang bersiyon para sa mga bata.

Kung edad 10–12 ka, gamitin lamang ang Middle School sa angkop na kapaligirang pang-edukasyon; huwag gamitin ang mga pangunahing pagninilay. Walang kasalukuyang bersiyon para sa batang wala pang 10. Dapat opsyonal ang paglahok. Hindi dapat kolektahin ng guro ang mga sagot na may pangalan o gawing grado ang indibidwal na marka. I-reset ang lokal na pagninilay pagkatapos gamitin sa device na may ibang gumagamit.

12. Mga pagpipilian at karapatan mo sa HISTI

  • sarilinin ang totoong pribadong impormasyon;
  • tumangging sagutin ang alinmang tanong;
  • iwanang walang sagot ang sensitibong tanong o gamitin ang mga available na pagpipilian;
  • bumalik, huminto, suriin, o mag-reset;
  • sarilinin ang resulta o ibahagi lang kapag pinili mo.

13. Ibang paraan

Dinisenyo ang HISTI upang hindi umasa sa iisang paraan ng paggamit ang mga kontrol sa pagkapribado:

  • Suriin: gamitin ang panel ng pagpapatunay sa pagkapribado o ang kasangkapan ng browser para sa imbakan ng site.
  • Burahin: gamitin ang I-reset ng HISTI o ang “burahin ang data ng site” sa browser.
  • Balikan: gamitin ang Balikan sa pahina ng resulta o bumalik sa pahina ng tanong.
  • Huwag magbigay ng teksto: pumili lang ng antas; walang patlang para sa pangalan o pribadong detalye.
  • Huwag sagutin ang sensitibong tanong: iwanang walang sagot ang bawat tanong o gamitin ang mga available na pagpipilian.

14. Pagsusuri sa pagkapribado at seguridad

May panel ng pagpapatunay sa pagkapribado ang pagninilay na nagsusuri sa nakikitang CSP, mga runtime resource mula sa parehong origin, mga key ng lokal na imbakan ng HISTI, at kung may cookie na nakikita ng pahina. Maaari mo ring suriin ang pampublikong source sa repository ng HISTI.

Walang teknikal na kontrol na kayang gawing lubusang ligtas ang isang pangkalahatang browser o device. Binabawasan ng disenyo ng HISTI ang pagpapadala ng data sa halip na mangako ng ganap na seguridad.

15. Mga pagbabago sa patakarang ito

Maaaring magbago ang patakarang ito kapag nagbago ang mga tampok, hosting, kontrol sa pagkapribado, o tagapagbigay ng serbisyo ng HISTI. Makikita ang kasalukuyang bersiyon sa petsa ng bisa sa itaas.

16. Pakikipag-ugnayan

Inihahanda pa ang hiwalay na email para sa HISTI at ilalathala rito kapag available na.

Huwag ipadala sa email ang mga sagot sa pagninilay, password, code, detalye ng account, o ibang sensitibong impormasyon.
