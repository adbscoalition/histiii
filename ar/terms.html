1. استخدام HISTI

بدخول HISTI أو استخدامه توافق على شروط الخدمة. إن لم توافق فلا تستخدم الخدمة.

سياسة العمر. HISTI الكامل وHISTI-120 وHISTI-60 غير مخصصة لمن دون 13 عامًا. الأنشطة المدرسية المنفصلة للمرحلة المتوسطة (10–13) والثانوية (14–18)، في بيئة تعليمية مناسبة، بمشاركة اختيارية وبديل لا يتطلب الإفصاح. لا تجمع إجابات الطلاب بأسماء ولا تجعل الدرجات الفردية علامات. لا يطلب HISTI تواريخ ميلاد أو تفاصيل خاصة حقيقية. تأتي إصدارات الأطفال الأخرى لاحقًا.

يمكنك التوقف عن استخدام HISTI في أي وقت وإعادة ضبط البيانات المحلية من واجهة التأمل.

2. ما هو HISTI

HISTI أداة تأمل ذاتي في مشاركة المعلومات. يساعدك على وصف ما شاركته أو قد تشاركه مع شخص أو جمهور، ويلخص الإجابات بقواعد الاحتساب الخاصة به.

HISTI ليس تشخيصًا أو رأيًا قانونيًا أو شهادة أمان أو تقييم مخاطر مهنيًا أو اختبار شخصية أو قياسًا لأخلاقك. لا تحدد النتيجة ما إذا كان إفصاح معين آمنًا أو غير آمن أو ضروريًا أو قانونيًا أو نافعًا أو ضارًا.

3. أبقِ المعلومات الخاصة الحقيقية خارج HISTI

صُمم HISTI لتجيب باختيار أوصاف. لا تكتب أو تلصق القيمة الخاصة أو الحساسة الحقيقية في الموقع.

  • لا تدخل كلمات مرور أو رموز استرداد أو رموزًا لمرة واحدة أو إجابات أمان أو مفاتيح خاصة أو أسرار مصادقة؛
  • لا تدخل أرقام الحسابات أو البطاقات أو البنوك أو الهويات الحكومية الكاملة أو أرقام هوية مماثلة؛
  • لا تدخل عناوين خاصة دقيقة أو محتوى وثائق خاصة أو معلومات أخرى لا تريد كشفها؛ و
  • اختر مستويات إجابة فقط؛ لا تطلب التأملات الحالية اسمًا أو نصًا بتفاصيل خاصة.

4. اختياراتك وحقوقك عند استخدام التأمل

  • يمكنك رفض أي سؤال.
  • يمكنك ترك الأسئلة الحساسة بلا إجابة أو استخدام الخيارات المتاحة.
  • يمكنك الرجوع أو المراجعة أو التوقف أو إعادة البدء.
  • لا يلزمك مشاركة النتيجة.
  • تبقى مسؤولًا عن تحديد المعلومات التي تكشفها خارج HISTI، إن كشفت شيئًا.

5. الخصوصية والبيانات المحلية

صُممت الإجابات والتقدم للبقاء في متصفحك. يستخدم HISTI تخزين localStorage للمتابعة لاحقًا، مع سجلات منفصلة لكل اختبار ولغة وشخص. لا يضع HISTI ملفات تعريف ارتباط أو يستخدمها للتأمل.

تمسح إعادة البدء تأمل الاختبار واللغة والشخص الحالي فقط. تستطيع أدوات بيانات الموقع في المتصفح إزالة كل بيانات HISTI المحلية لهذا النطاق، بما فيها القديمة. لا تتضمن التأملات الحالية تصدير JSON أو واجهة سجل نتائج.

تستخدم الخدمة في الإنتاج سياسة أمان محتوى تتضمن connect-src 'none' و form-action 'none'. راجع سياسة الخصوصية للتفاصيل التقنية وحدود هذا البيان، بما فيها طلبات الاستضافة الثابتة العادية.

6. المشاركة قرارك

لا تشارك صفحة النتائج الحالية نتيجة أو ترفعها أو تنشرها تلقائيًا. إن نسختها أو حفظت لقطة أو أرسلتها إلى تطبيق أو شخص، فلا يتحكم HISTI بما تفعله الوجهة بها.

راجع كل شيء قبل مشاركته. لا تشارك نتيجة إن كانت تكشف معلومات تريد إبقاءها خاصة.

7. الاستخدام المقبول

لا تستخدم HISTI لتعطيل الخدمة أو تجاوز ضوابط الأمان أو إيذاء الآخرين أو توزيع برامج ضارة أو مخالفة القانون المعمول به.

لا تعرض نتيجة HISTI بوصفها تشخيصًا مهنيًا أو حكمًا قانونيًا أو شهادة أمان أو حكمًا رسميًا على شخص آخر.

8. التوفر والتغييرات

يمكن تغيير HISTI أو تحديثه أو مقاطعته أو إيقافه. قد تتغير الميزات والأسئلة وقواعد الاحتساب والصياغة والعرض مع الوقت.

قد تصبح البيانات المحلية غير متوافقة مع إصدار قادم أو تضيع إن مسح المتصفح بيانات الموقع. إن كانت نتيجة تهمك فاحتفظ بنسخة خاصة بك.

الاختبار. تُرخص مواد اختبار HISTI، ومنها صياغة الأسئلة وخيارات الإجابة والتعليمات وقواعد الاحتساب، بموجب رخصة المشاع الإبداعي نَسب المُصنَّف — منع الاشتقاق 4.0 دولي (CC BY-ND 4.0). ينطبق هذا الترخيص على محتوى التقييم، لا الموقع أو البرنامج الذي يعرضه ويحسب درجاته.

يجوز نسخ الاختبار وإعادة توزيعه دون تغيير، حتى تجاريًا، مع النسب المناسب ورابط الترخيص. احتفظ باعتمادات المبدعين وإشعارات الحقوق والترخيص وإخلاء المسؤولية وروابط الأصل. لا يسمح الترخيص بتوزيع مواد اختبار معدلة أو الإيحاء بالتأييد.

لا تضيف عبارة حفظ حقوق الموقع وهذه الشروط قيودًا إلى أذونات CC BY-ND 4.0 للاختبار. لا تتأثر استثناءات حقوق النشر وحدودها القانونية. يسود نص الترخيص الكامل ؛ وهذا القسم ملخص.

تحتفظ خطوط الجهات الأخرى والموارد ذات الترخيص المنفصل بتراخيصها. تُقدم مواد الاختبار بلا ضمانات وفق شروط CC BY-ND 4.0.

10. دون ضمانات

يُقدم HISTI «كما هو» و«حسب التوفر» بالقدر الذي يسمح به القانون. قد تكون النتائج ناقصة أو غير دقيقة أو يساء فهمها أو تتأثر بطريقة تفسير الأسئلة.

لا ضمان لاستمرار توفر الخدمة أو خلوها من الأخطاء أو ملاءمتها لغرض معين أو لكل شخص أو موقف.

11. حدود المسؤولية

بأقصى قدر يسمح به القانون المعمول به، لا يتحمل HISTI ومشغلوه مسؤولية خسائر غير مباشرة أو عرضية أو خاصة أو تبعية أو مماثلة تنشأ عن استخدام الخدمة أو الاعتماد على نتيجة أو فقدان البيانات المحلية أو قرار المستخدم بمشاركة المعلومات.

لا تستبعد هذه الشروط حقوقًا أو مسؤوليات لا يجوز استبعادها قانونًا.

12. خدمات الجهات الأخرى

قد تدير جهات أخرى الاستضافة والمتصفحات وأنظمة التشغيل والتطبيقات التي تختارها للمشاركة، وفق شروطها. لا يتحمل HISTI مسؤولية تلك الخدمات.

13. تغييرات الشروط

قد تُحدث هذه الشروط مع تغير HISTI. يوضح تاريخ السريان أعلى الصفحة وقت بدء هذه النسخة. استمرار الاستخدام بعد التحديث يعني قبول الشروط المحدثة.

14. التواصل

يجري إعداد بريد تواصل مخصص لـ HISTI، وسيُنشر على الموقع عند توفره.

لا ترسل إجابات التأمل أو معلومات حساسة أخرى بالبريد الإلكتروني.
